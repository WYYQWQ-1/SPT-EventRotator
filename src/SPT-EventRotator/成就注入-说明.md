合计 **9 个成就 / 58 条 Quest 条件**（去重后 57 —— 战争之因 `b5bb719b…` 被两条分支各引用一次）。

id 规则（可复核）：`md5("SPT-EventRotator/achievement/<key>")[:24]`，分支线 key 用 `<线>/<分支>`
（`casus_belli/morituri`、`casus_belli/habet`、`tarkov_mystery/local_strong_man`、`tarkov_mystery/involved_in_peace`）；
条件 id = `md5("SPT-EventRotator/achievement/<key>/cond/<i>")[:24]`。

### 条件格式（ISB 实测，逐字）

```json
"conditions": { "availableForFinish": [ {
  "availableAfter": 0, "conditionType": "Quest", "dispersion": 0,
  "dynamicLocale": false, "globalQuestCounterId": "",
  "id": "<24 位 hex，唯一>", "index": 0, "parentId": "",
  "status": [4], "target": "<任务 id>", "visibilityConditions": []
} ], "fail": [] }
```

`status: [4]` = 任务成功。**多条条件是 AND**（已核客户端 `Conditional`：`TestConditionsExcept` 用 `.All(...)`，
成就与任务共用同一套 `Conditional` / `ProgressChecker` 机器）——所以「三选一」类分支**不能**塞进同一条成就，
必须拆成多条成就；反过来「任一结局」这类表达（8 个互斥 id）本注入器**做不到**。

### 其余字段取值依据（本机 `achievements.json` 53 条实测，未变）

`assetPath/prefab` 空、`instantComplete/showConditions/progressBarEnabled/hidden` 全 false、`rewards: []`、
`index` 用 20001~20011（新增用 20010/20011；删掉的 20001/20004 留空不复用）、
`showNotificationsInGame: true`（故意偏离本机 53/53 的 false，与 ISB 一致）；
`rarity`：新建的 7 条统一 `Legendary`，两条保留的自建线维持原 `Rare`。
`name`/`description` 字段 SPT 模型没有对应属性，进 `ExtensionData` 原样回传；真正文案是本地化键 `<id> name` / `<id> description`。

## 3. 逐条处置理由

### 3.1 删除两条（官方已有）
- **万圣节**：官方是**双分支**——`670febed`「致命结果」(协助感染者摧毁病毒) / `670feb95`「彻底缓解」(治愈所有感染者)。
  我们那条「不眠之夜」把 10 条感染者任务全塞进 AND，语义上等于「两边都做」，官方口径下只会变成第三条并列。
- **军备竞赛**：官方 `668bf47c`「高端竞赛」已在表里，活动名与成就名一一对应。
- ⚠ **必须先说清楚的代价**：这两条官方成就的**条件是诱饵**（见 §4），SPT 里永远不会解锁。
  删除后这两个活动「成就列表里有一条、但谁都点不亮」——这是官方数据的原样行为，不是本轮引入的 bug。

### 3.2 改名三条（官方有名字、本机无条目）
- **灾厄侦探 Scourging**：`灾厄来袭`任务线里逐条对话正是「Ref 派人去实验室、探明他在找什么」
  （`Hidden Route`：*Ref is planning … operation on someone else's turf*；`Extending the Operation`：*Ref is hoping to steal stimulants*）。
  与官方描述「完成"灾厄来袭"任务线，探明裁判在实验室的搜寻目标」逐字对得上。
- **隐入黑暗 Going Dark**：官方描述「与黑色军团部队交战，并完成"大停电"活动任务线」；
  我们 5 条任务的 devNote 记录击杀目标含 `blackDivAssault / bossWedge / blackDivIb`（黑色军团），活动名 `Blackout`。完全对应。
- **我即法律 I Am the Law**：官方描述「帮助 Jaeger 恢复自然保护区的秩序，并完成"狂野森林"任务线」；
  第 1 条任务 trader=`5c0647fdd443bc2504c2d371`（Jaeger），场景 Priozersk（自然保护区）。完全对应。

### 3.3 灾厄线为什么是 6 条而不是 7 条
`questlines\scourge_incursion.json` 里有 7 个任务，第 7 个 `6a91840a740be0cff50e0310`（初步勘察 / Preliminary Survey）
**没有前置任务**（只有 `Level ≥ 5`），且 `events_wiki.txt` 里它是 **2026-09-01 的独立 wiki 章节**
`==Preliminary Survey (1 September 2026)==`（正文只有一句 *Quest [[Preliminary Survey]] has been added*）。
⇒ 它不属于「灾厄来袭」任务线，放进成就条件会让成就永远差一条无关任务。**成就只取前 6 条**（questline 文件本身未改）。

### 3.4 塔科夫之谜：官方三条，只建两条（第三条表达不了）
**能表达**：选边在这份数据里是**互斥任务 id**（不是抽象 enum），用 Quest 条件就能判。入口一对互斥（`Fail` 互挂 `status:[2,3,4]`）：

| 分支 | 入口任务 | 我方条件 |
| --- | --- | --- |
| 街头大力士（Skier 方） | `66040e19` 突破口 Break Through（Skier 发） | 入口 + 线形主干 4 条（`660427dd`/`6604287a`/`66042e3b`/`6616a96a`），共 5 |
| 和平精英（Peacekeeper 方） | `66040f01` U 字回转 U Turn（Peacekeeper 发） | 入口 + 线形主干 4 条（`66042b8b`/`66042c0d`/`6605852a`/`6616a9fd`），共 5 |

两条线**完全平行、无共享 id**（不会互相阻塞），已逐条核对前置链。

**表达不了**：`首席大臣 Cardinal Richelieu`（官方描述：*Find out who actually controls Tarkov*）对应的是**结局选择**——
把东西交给 Lightkeeper 的 `Ding-Ding-Ding`。但结局有 **8 个互斥 id**，取决于路线组合（2 入口 × 2 线内 × 主线/最后机会）：

```
660ab96ef50cbdad7906e080  660acbac1d2f7aa65505e056  660acf9b2392822f6e0dc0a5  660ad1902392822f6e0dc0bd
08933600828b8a218248f6ad  625a4a3cceacb087cb3ecfa9  599fc850cd893349582bad81  7d5b0064cbf8037884b476cd
```

注入器只支持 **AND**（`availableForFinish` 全满足），无法表达「这 8 个里任意一个」；写 8 条只会变成要求全部 8 条（永远不可能），
写单条只覆盖 1/8 的玩家。⇒ **不建**（也不写死某个 id）。要补这条，得先让注入支持「OR 组」（本轮约束不改注入逻辑）。

另外：原来那条「谜底」要求 66 条**全部**完成，而两条线互斥 ⇒ 它本来就**永远点不亮**，本轮顺带把这个错误清掉了。

### 3.5 战争之因：官方双分支，能表达，拆两条
7 条任务本身就是「共同开头 + 两侧各 3 条 + 中间一对互斥」：

```
战争之因 b5bb719b（共同）
├─ 裁判线：留条后路 9882cf75（Ref 发）→ 回收失物 1349dec1 → 赴死之人向你致敬 2c9d5272
└─ Skier 线：摘浅作战 2dd3d24a（Skier 发）→ 挖墙脚 ddf04260 → 得吃！ 6c674980
互斥：回收失物 ⇄ 摘浅作战（Fail 互挂 status:[4]）
```

⇒ 「赴死之人向你致敬」= 共同 + 裁判侧 3 条；「得吃！」= 共同 + Skier 侧 3 条。**不再有一条中立的「开战理由」成就。**

### 3.6 保留两条（官方确实没有）
`The TerraGroup Trail`（2023-07-28）与 `Down the Rabbit Hole`（2023-12-02）在官方 21 条成就清单里**都没有**，
本机 53 条成就表里也没有对应项（已逐条比对 53 个名字）。保留自建，但名字从我们自造的
「追迹者 / 坠入深渊」换成**活动名**（与官方成就命名法一致：`Khorovod`、`Targrad Tales` 都是活动名），描述统一成
「完成"XXX"任务线。」的官方句式。

## 4. ⚠ 重要发现：官方成就的条件是诱饵

本机 53 条成就的 `conditions.availableForFinish` **92 条全是 `CounterCreator`、4 条 `Block`，没有一条 Quest 条件**。
例如「致命结果」的真实条件是*用霰弹枪在 ≥10000 米外爆头击杀 10000 名 Savage（role=shooterBTR）*——不可能完成。
⇒ 官方解锁判定在**服务器端**，`achievements.json` 里的条件是给客户端看的占位/诱饵，SPT 无法复现。
这也是本 mod 必须自己写 Quest 条件成就的根因；同时也意味着**「官方已有 → 我们删除」之后，那个活动在 SPT 里没有可解锁成就**。
